# Getting Started With Cursor

## 1. Download [Cursor](https://www.cursor.com)

## 2. Create an account after installing cursor

## 3. Clone this repository in Cursor

## 4. Start docker

## 5. Add the database to Docker
Navigate to docker-codefest folder and type "docker-compose up -d" in the terminal of Cursor

## Examples of exercises:

1. Write some tests
2. Add a feature
3. Add some form of security (E.g., OAuth2)
4. Bugfixes

## Postman
In the resources folder a json file can be found containing some rest calls. You can import this file in the Postman app.
